# **🎮 Project Title: Gaming Data Analytics using Power BI and Machine Learning**

# **📘 Project Description**

This project focuses on analyzing player behavior and engagement in gaming platforms using Power BI and Python-based machine learning models.

The primary goal is to understand player patterns, predict future actions (like churn or in-game purchases), and visualize insights that support decision-making for gaming companies.

# **🔍 Objective**

* To design an end-to-end analytics system that integrates:

* Data Modeling & Cleaning (Python & Power BI)

* Predictive Analysis (Machine Learning)

* Interactive Visualization (Power BI Dashboards)

* DAX Query Optimization for KPIs such as player segmentation, profit, and playtime trends.

# **📊 Key Features**

* Data Modeling Dashboard – Summarizes average session length, player count, and total play hours by country.

* DAX Query Dashboard – Calculates key metrics like total profit, average session, and multiplayer session statistics using DAX measures.

* Visualization Dashboard – Displays player segments, total spending, purchase probability, and country-wise engagement trends.

* AI Tools Dashboard – Uses Power BI AI visuals to reveal insights such as churn probability, top segments, and key influencers.

* Python Integration (.ipynb) – Includes preprocessing, feature extraction, model training (Decision Tree, Random Forest, Logistic Regression), and performance evaluation.

# **🧠 Machine Learning Insight**

* Models were trained to predict:

* Player segment classification (Casual, Regular, Elite, Competitive)

* Churn probability

* In-game purchase likelihood

# **🛠️ Tools & Technologies**

* Power BI (Data Modeling, DAX, AI Visuals)

* Python (pandas, matplotlib, scikit-learn, seaborn)

* Machine Learning Models: Random Forest, Logistic Regression, Decision Tree

* Dataset: Player behavior metrics (playtime, sessions, purchases, countries, etc.)

# **💡 Outcome**

* Identified top-performing player segments and countries (e.g., USA & Brazil).

* Predicted churn probabilities with improved accuracy.

* Delivered interactive dashboards enabling data-driven decision-making for gaming companies.
